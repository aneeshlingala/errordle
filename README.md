# Errordle - Programming Puzzles

### Info

Errordle is a game where you choose your difficulty (easy, medium, hard) and your coding language. The program connects to the OpenAI-based BazaarLink API to retrieve broken code samples and give feedback on the user's work. 

### API Key and Usage
Go to https://bazaarlink.ai and click sign in. Then, click sign up and sign up with your email, continue with Google, etc. Then, click create a key, give it a name, and click create. Next, create an environment variable named ERRORDLE_KEY and put your key in there. The API has a 1min limit for $5 or an hour limit for $25. One run uses about 0.03cents or even less.

### How to use
The best way to use Errordle is to run the latest .exe (windows, wine, etc). The Python script can be used, but for easier use, the binaries are better.
